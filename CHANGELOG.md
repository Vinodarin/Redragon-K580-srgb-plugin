# Changelog

Все значимые изменения этого проекта будут документироваться в этом файле.

## [1.0.0] - 2026-05-01
### Added
- Базовый функционал управления подсветкой Redragon K580 Vata через SignalRGB.
- Поддержка режимов Canvas и Forced.
- Настройка монохромного режима.
- Параметры пакетов: размер, пауза, контрольная сумма.
- Настройка FPS.

## [1.1.0] - 2026-05-02
### Improved
- Добавлены уведомления при инициализации и успешном подключении устройства.
- Добавлено уведомление «Подсветка активна» после первого рендера.
- Улучшена обработка ошибок при поиске эндпоинтов.

## [1.2.0] - 2026-05-03
### Enhanced
- Добавлены тематические значки (эмодзи) ко всем логам для наглядности.
- Финальное сообщение «✅ Все пакеты успешно отправлены» при Basic‑логах.
- Убраны дублирующие строки логов (`Created Leds`, `Set size`, `Loaded overrides`).
- Чистый вывод: системные `info` остаются, кастомные логи только там, где движок сам ничего не пишет.
- **Добавлен параметр выбора уровня логов (None, Basic, Verbose).**
