# Redragon K580 SignalRGB Plugin

Приватный репозиторий для разработки кастомного плагина SignalRGB под клавиатуру Redragon K580.

## 📁 Структура проекта

- `src/` — исходный код плагина  
- `usb-captures/` — USB-трафик для анализа  
- `docs/` — заметки по протоколу и реверсу  
- `examples/` — тестовые скрипты и примеры  

# Redragon K580 Vata SignalRGB Plugin

Плагин для управления подсветкой клавиатуры **Redragon K580 Vata** через SignalRGB.  
Добавлены улучшенные логи с тематическими значками, уведомления и удобные настройки.

## ✨ Возможности
- Управление подсветкой (Canvas / Forced режимы)
- Настройка монохромного режима
- Гибкая настройка пакетов (размер, пауза, контрольная сумма)
- Настройка FPS (15, 30, 45, 60)
- **Выбор уровня логов**: None, Basic, Verbose
- Уведомления о состоянии устройства
- Красивые логи с иконками для наглядности

## 📑 Уровни логов
- **None** — логи полностью отключены, вывод минимален.  
- **Basic** — выводятся только ключевые события: инициализация, успешная отправка пакетов, ошибки.  
- **Verbose** — подробный режим: включает все технические детали (эндпоинты, расчёт контрольной суммы, каждый пакет).
